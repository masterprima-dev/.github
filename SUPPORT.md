# Getting Support

- **Bug in a repo?** Open an issue with the bug report template.
- **Feature idea?** Open an issue with the feature request template.
- **Security issue?** Don't open a public issue. See [SECURITY.md](SECURITY.md).
- **Question about Masterprima's programs, registration, or branches?** That isn't handled here. Visit [masterprima.com](https://masterprima.com).
