> The three lockups use **white text on a transparent background**. They are only legible on dark or colored backgrounds. They will look blank on white (including GitHub light mode).

The mark is an orange circle with a white "MP" and a yellow accent (the stem shared by M and P).

## Colors

From [`assets/brand/warna-branding.png`](assets/brand/warna-branding.png). CMYK is the official spec. Hex values are screen approximations sampled from that image, so use the CMYK values for print.

### Primary

| Name | CMYK | Hex |
| --- | --- | --- |
| Orange mendekati merah | C0 M85 Y100 K0 | `#E94F25` |
| Deep yellow | C0 M20 Y100 K0 | `#FDD100` |
| Putih | C0 M0 Y0 K0 | `#FFFFFF` |

### Supporting

| Name | CMYK | Hex |
| --- | --- | --- |
| Sky blue | C100 M0 Y0 K0 | `#00A2E9` |
| Abu-abu | C0 M0 Y0 K30 | `#C9CACA` |
| Black | C0 M0 Y0 K100 | `#332C2B` |

The mark itself renders a slightly more saturated orange (`#F3490B`) and yellow (`#FDC801`) than the palette swatches. That is how the logo file is drawn. Do not recolor the logo to match the swatches.
